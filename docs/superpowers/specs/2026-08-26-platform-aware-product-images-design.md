# 平台化商品图规划、尺寸标注与水印设计

日期：2026-08-26

## 目标

在现有“上传产品图 → AI 分析 → 确认规划 → 批量生成”流程上增加稳定、可编辑的平台化生成规则：

- 编辑器内的生图提示词统一使用中文；
- 第 1 张固定为白底商品主图；
- 第 2 张固定为带准确尺寸信息的商品图；
- 支持灵活的产品尺寸项，而不是固定长、宽、高；
- 平台自动决定图片营销文案和尺寸标签语言；
- 新增 Ozon 平台与俄文；
- 新增原生 1K `3:4` 竖版，即 `1090×1443`；
- 支持程序固定叠加的文字水印；
- 预览、单张下载和批量下载得到相同的处理后图片。

本次不增加数据库、账号系统、长期图片存储、Logo 图片水印或新的生图供应商。

## 用户流程

1. 用户上传 1–6 张产品参考图。
2. 用户填写产品名称、补充要求和灵活尺寸项。
3. 用户选择平台、比例和生成数量，并可填写文字水印。
4. 平台选择自动决定营销文案和尺寸标签语言；仅“通用电商”允许手动选择。
5. AI 分析商品并返回可编辑规划。规划标题、目标、场景和提示词均显示中文；图片内文案使用目标平台语言。
6. 程序校正前两张规划，保证白底主图和尺寸标注图的位置固定。
7. 用户确认后批量生成。Grsai 返回源图后，服务端按签名配置叠加尺寸标注与水印。
8. 页面预览与下载均读取同一处理接口，避免“预览有水印、下载无水印”之类的不一致。

## 数据模型

### 尺寸项

新增 `DimensionItem`：

```ts
type DimensionItem = {
  id: string;
  label: string;
  value: number;
  unit: "mm" | "cm" | "m" | "in" | "ml" | "l" | "custom";
  customUnit?: string;
};
```

规则：

- 最多 6 项；
- `label` 必填，去除首尾空白后为 1–24 个字符；
- `value` 必须是有限的正数；
- `custom` 单位必须填写 1–12 个字符的 `customUnit`；
- 生成数量为 2–16 时至少需要 1 条有效尺寸；
- 生成数量为 1 时尺寸可为空；
- 尺寸变化会使已有分析和任务失效，要求重新分析。

尺寸项支持任意业务名称，例如“杯口直径”“杯高”“容量”“肩宽”“线长”，不限定为长、宽、高。

### 生成设置

扩展现有 `GenerationSettings`：

- `platform` 新增 `ozon`；
- `language` 新增 `ru`；
- `aspectRatio` 新增 `1090x1443`；
- 新增 `watermark: string`，最多 40 个字符；空字符串表示不叠加水印。

现有“无文字”调整为“无营销文案”。它只禁止广告文案，不禁止第 2 张的尺寸标签或用户明确输入的水印。

### 规划项

扩展 `PlanItem`，增加经过校正的尺寸标注数组：

```ts
type DimensionAnnotation = {
  label: string;
  displayValue: string;
};

type PlanItem = {
  // 现有字段保持不变
  annotations: DimensionAnnotation[];
};
```

只有第 2 张必须包含 `annotations`；其余图片默认空数组。AI 可以翻译标签，但程序负责写入换算后的数值和单位，不能采用 AI 自行返回的数值。

## 平台语言映射

固定映射如下：

| 平台 | 营销文案与尺寸标签语言 | 用户能否手动修改 |
| --- | --- | --- |
| 淘宝 / 天猫 | 中文 | 否 |
| 抖音商城 | 中文 | 否 |
| Amazon | 英文 | 否 |
| Shopify | 英文 | 否 |
| Ozon | 俄文 | 否 |
| 通用电商 | 无营销文案 / 中文 / 英文 / 俄文 | 是 |

前端切换固定平台时同时更新语言；服务端再次校验平台与语言组合，避免手工请求绕过。

通用电商选择“无营销文案”时，营销 `copy` 保持为空；尺寸名称继续采用用户输入的中文，尺寸单位按中文规则显示。

## 单位换算与本地化

用户可以使用任一标准输入单位，程序在分析请求前换算成平台单位：

| 目标语言 | 长度 | 容量 |
| --- | --- | --- |
| 中文 | `cm` | `mL` / `L` |
| 英文 | `in` | `fl oz` |
| 俄文 | `см` | `мл` / `л` |

换算规则：

- `10 mm = 1 cm`；
- `1 m = 100 cm`；
- `1 in = 2.54 cm`；
- `1 US fl oz = 29.5735 mL`；
- 中文和俄文容量小于 `1000 mL` 时显示 `mL` / `мл`，达到 `1000 mL` 时换算为 `L` / `л`；英文容量统一换算为 `fl oz`；
- 显示值最多保留两位小数并移除无意义的尾随零；
- `custom` 单位不做数值换算，单位文字原样保留；尺寸名称仍按目标语言翻译。

程序生成带稳定索引的待翻译尺寸列表。AI 只返回相同数量、相同顺序的目标语言标签；解析后程序将翻译标签与自己的 `displayValue` 合并。如果返回数量或结构错误，沿用现有一次 JSON 修复流程；修复后仍错误则提示重新分析。

## 固定图片规划规则

AI 分析提示词明确要求所有规划标题、目标、场景和 `prompt` 使用中文；`copy` 和尺寸标签使用目标平台语言。

解析 AI 返回后，程序再执行确定性校正：

### 第 1 张：白底商品主图

- `type` 强制为 `main`；
- 纯白背景，RGB `255,255,255`；
- 只展示当前销售商品，不改变结构、颜色、材质、Logo 或 SKU；
- 商品完整、居中、清晰，不裁切主体；
- 不生成营销文案；
- 标题、目标、场景和提示词使用固定中文模板。

### 第 2 张：尺寸标注图

仅在生成数量至少为 2 时存在：

- `type` 强制为 `detail`；
- 商品放置在画面左侧约 65% 的主体区，右侧约 35% 保持干净，作为尺寸标注区；
- AI 负责生成干净、适合标注的商品底图，不负责写尺寸数值；
- 程序在右侧标注区纵向排列 1–6 条准确标签，并为每条标签绘制指向商品主体区的引导线；
- 标题、目标、场景和提示词使用固定中文模板。

### 第 3 张及以后

AI 根据商品事实、目标平台、目标语言和用户补充要求规划场景、卖点与细节图。不得臆造认证、功效、成分、规格或价格。

## 3:4 原生生成

新增比例选项：`3:4 竖版（1090×1443）`。

选择该比例时直接向 Grsai `gpt-image-2` 发送：

```json
{
  "aspectRatio": "1090x1443"
}
```

不进行二次裁切或拉伸。现有比例继续按原值提交。

## 水印规则

首版只支持文字水印，不支持上传 Logo 图片。

- 水印文字最多 40 字；
- 固定右下角；
- 使用半透明文字、轻微描边或阴影和安全边距，保证浅色、深色背景下均可见；
- 水印文字进入 SVG 前必须进行 XML 转义；
- 水印为空时不处理；
- Amazon 第 1 张不加水印；
- Amazon 第 2 张及以后加水印；
- 其他平台所有图片（包括第 1 张）均加水印。

水印不交给 AI 绘制，以避免错字、变形和位置不一致。

## 图片处理与安全令牌

增加服务端图片处理依赖 `sharp`。处理顺序：

1. 验证签名令牌和有效期；
2. 仅请求令牌中的 HTTPS 源图；
3. 拒绝重定向、非图片响应和超过限制的源文件；
4. 自动旋转源图；
5. 第 2 张叠加尺寸引导线与尺寸文字；
6. 按平台和序号规则叠加水印；
7. 输出 PNG。

现有下载令牌扩展为签名渲染配置，包含：

- Grsai 源图 URL；
- 图片序号；
- 尺寸标注；
- 水印文字；
- 是否应用水印；
- 过期时间。

异步提交返回的供应商任务 ID 不再单独裸传。服务端签发短时任务令牌，任务令牌包含供应商任务 ID 和同一份渲染配置；轮询接口验证后再查询 Grsai，并在成功时签发下载令牌。这样异步完成后不会丢失水印或尺寸配置，也不能通过修改查询参数伪造处理规则。

成功任务中的 `resultUrl` 指向同源图片处理接口的 `inline` 模式，`downloadToken` 指向同一处理配置的附件下载模式。大图预览、单张下载和 ZIP 下载因而使用相同像素内容。

不缓存长期结果；继续采用短时签名令牌与 `private, no-store`。

## 前端改动

### 产品信息

在产品名称和补充要求之间增加“产品尺寸”：

- 初始显示一条尺寸项；
- 支持新增和删除，最多 6 条；
- 每行包含名称、数值、单位；
- 选择“自定义”后显示自定义单位输入；
- 在开始分析前显示就地校验错误。

### 生成设置

- 平台列表新增 Ozon；
- 固定平台下语言选择框显示自动结果并禁用；
- 通用电商允许手动选择；
- “无文字”重命名为“无营销文案”；
- 比例列表新增 `3:4 竖版（1090×1443）`；
- 增加文字水印输入框和长度提示。

### 规划编辑器

- 提示词标签明确为“中文生图提示词”；
- 第 2 张显示只读的尺寸标注预览；
- 用户仍可编辑标题、目标、场景、营销文案和中文提示词；
- 确认生成前重新验证固定图片规则和尺寸标注。

## 错误处理

- 尺寸缺失或无效：阻止分析并指出具体尺寸行；
- 平台语言不匹配：服务端返回 400；
- AI 翻译标签数量不匹配：执行一次修复，仍失败则提示重新分析；
- 任务令牌或下载令牌被篡改、过期：返回通用无效提示，不泄露令牌内容；
- 源图非 HTTPS、重定向、格式错误或过大：图片处理失败；
- `sharp` 处理失败：明确提示图片处理失败，不回退为未加水印的原图；
- Grsai 连接、鉴权、余额、审核和超时错误继续沿用现有分类。

## 测试策略

所有测试使用本地夹具和模拟 Grsai 响应，不产生真实生图费用。

### 模型与纯函数

- Ozon、俄文和 `1090x1443` 能通过 schema；
- 固定平台只接受匹配语言；
- 灵活尺寸项和生成数量联动校验；
- 长度、容量和自定义单位转换；
- 第一、第二张规划校正；
- 所有编辑器提示词为中文；
- Amazon 与其他平台水印规则。

### API 与安全

- 分析路由正确接收尺寸项；
- 生成路由签发带渲染配置的任务/下载令牌；
- 任务令牌和下载令牌防篡改、过期检查；
- 图片代理拒绝非 HTTPS、重定向、非图片和过大内容；
- 使用小型本地图片夹具验证尺寸标注和文字水印确实改变输出；
- `inline` 预览和附件下载的像素内容一致。

### 组件与工作流

- 尺寸项新增、删除、自定义单位与错误提示；
- 平台切换自动更新并锁定语言；
- Ozon 显示俄文；
- 水印输入和 3:4 选项；
- 修改尺寸或水印会使旧分析失效；
- 模拟完成“分析 → 编辑 → 生成 → 轮询 → 预览/下载”流程。

## 验收标准

- 用户可输入多样化尺寸项；
- 第 1 张始终为白底商品主图；
- 生成至少 2 张时，第 2 张始终包含准确的本地化尺寸标注；
- 编辑器中的生图提示词均为中文；
- Amazon、Shopify 使用英文，Ozon 使用俄文，淘宝/天猫与抖音使用中文；
- 3:4 选项向 Grsai 提交 `1090x1443`，结果无需裁切；
- Amazon 第 1 张无水印，其他应加水印的图片均稳定显示用户文字；
- 页面预览、单张下载和批量下载内容一致；
- 现有 1–16 张生成、失败重试、继续轮询和临时下载能力不回归；
- 单元测试、组件测试、API 测试、端到端测试、Lint、类型检查和生产构建全部通过。
